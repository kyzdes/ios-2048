# 2048 Mac

A native, notarized, ad-free **2048** for macOS. SwiftUI. Free. Open source. No tabs, no telemetry.

- **Landing:** [2048.moone.dev](https://2048.moone.dev/)
- **Latest release:** [GitHub Releases](https://github.com/kyzdes/ios-2048/releases/latest) — signed + notarized DMG/ZIP
- **macOS:** 14.0+

## Build from source

Requires Xcode 15+ and [xcodegen](https://github.com/yonaskolb/XcodeGen).

```bash
xcodegen           # regenerate .xcodeproj from project.yml
xcodebuild -project Game2048.xcodeproj -scheme Game2048Mac -configuration Release
```

## Release

The `script/release.sh` flow signs and notarizes both `.app` (zipped) and `.dmg`. Prerequisites: Apple Developer ID Application cert in Keychain + a `notarytool` profile. See [`script/RELEASE.md`](script/RELEASE.md) for the full setup.

```bash
./script/release.sh
# → build/release/Game2048Mac.dmg  (signed, notarized, stapled)
# → build/release/Game2048Mac.zip  (signed, stapled)
```
